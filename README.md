# New English

Учебное Flutter-приложение для ребёнка 2 класса: английский алфавит, звуки, буквосочетания и первые навыки чтения.

## Первый прототип

- урок `SH → /ʃ/`;
- примеры `ship`, `fish`, `shop`;
- британское произношение слов через TTS;
- отдельное место для эталонной записи фонемы;
- мини-тест после урока;
- архитектура для следующих уроков `CH`, `TH`, гласных и алфавита.

## Запуск

Если Flutter уже установлен:

```bash
flutter pub get
flutter run -d chrome
```

В Codespaces можно запустить веб-версию так:

```bash
flutter pub get
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 3000
```

Если в репозитории ещё нет платформенных папок Flutter, один раз выполните:

```bash
flutter create .
```

После этого снова выполните `flutter pub get`.
