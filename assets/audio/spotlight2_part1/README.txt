Эта папка предназначена для локальных аудиофрагментов из официального бесплатного аудиоприложения «Английский в фокусе / Spotlight 2», 2 класс, часть 1, издательство «Просвещение».

Официальное аудио является главным эталоном произношения для приложения.

ВАЖНО: сам аудиокурс не публикуем в открытом GitHub-репозитории. Скачайте его с официального источника издательства и подготовьте необходимые короткие фрагменты локально.

Соглашение об именах, которое уже поддерживает приложение:

letter_A.mp3 ... letter_Z.mp3
word_apple.mp3
word_cat.mp3
word_dog.mp3
phoneme_a.mp3
phoneme_sh.mp3
phoneme_ch.mp3
phoneme_th_thing.mp3
phoneme_th_that.mp3
...

Если соответствующий официальный файл существует здесь, приложение использует его первым. Если файла нет, используется резервный локальный файл assets/audio/, а затем TTS (только для разработки).
